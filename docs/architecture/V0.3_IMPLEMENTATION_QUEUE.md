## Revalidation outcome — 2026-09-20

The Q1 preparation was critically reviewed against external research and the current implementation.

The main correction is:

    Coordinator over independent journals
        !=
    physical transaction boundary

The long-term authoritative control-plane state should therefore live behind one transactional persistence boundary or an equivalently proven CAS protocol.

SQLite/Room is the strongest current backend candidate, but it remains OPEN until the schema and invariant matrix are demonstrated.

The existing journal should be treated as compatibility/migration infrastructure unless stronger atomicity and cross-process CAS semantics are actually proven.

The product thesis was also revalidated:

    primary thesis = user-owned Agent Runtime / Control Plane
    developer capabilities = proving ground
    generic universal assistant = not the primary bet
    commercial PMF = UNKNOWN

## Now

### Q1 — Unified durable control-plane transaction

Targets A-02/A-03/A-04.

Current gate:

    SCHEMA PROPOSED
    INVARIANT MATRIX PROPOSED
    IMPLEMENTATION NOT YET APPROVED

Before writing the backend, resolve:

1. execution admission versus RUNNING semantics;
2. exact ExecutionClaim lifecycle;
3. effect-group aggregate-state invariant strategy;
4. zero-effect Action semantics;
5. stale-write/versioning mechanism;
6. event/provenance requirement;
7. deterministic legacy-journal migration semantics.

After those are resolved:

    1. Add the authoritative transactional backend.
    2. Add state-transition result types.
    3. Add execution-claim identity/lifecycle.
    4. Add atomic group-reservation transaction.
    5. Make terminal writes transition-checked.
    6. Add deterministic fault-injection tests.
    7. Test multiple database connections/instances.
    8. Test reopen/recovery after each fault point.
    9. Re-run the complete transaction matrix.

SQLite/Room is the preferred backend direction based on its transaction and concurrency primitives, but this remains an implementation decision until the schema/invariant review is closed.
